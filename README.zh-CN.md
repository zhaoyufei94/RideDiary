# RideDiary / 途记

<img src="docs/brand/ridediary-logo.svg" width="96" height="96" alt="RideDiary 标志" />

**每天的骑行，多一点了解** · [English](README.md) · [更新记录](CHANGELOG.zh-CN.md)

当前版本：**0.3.4**

途记是一款离线优先的骑行手记，记录日常通勤，帮你了解时间花在哪里，并与同路线的历史行程比较。支持 Android 8.0 及以上，无需账号、额外硬件或 Google Play 服务。

## 主要功能

- **记录行程**：查看耗时、里程、均速、静止时间和定位状态；实时展示候选路线与重合度，识别路线后显示摩托车进度条。
- **出发前看天气**：当前天气、未来一小时降水概率、今日概览，以及路线出发时段的体感温度预览。
- **出发前看路况**：出发前两小时至后一小时展示当前路况，与天气同步刷新；复用已有百度地图 AK，无需新增密钥。耗时为驾车参考，暂不提供未来预测。
- **出行计划**：上下班分别设置工作日或自定义星期及出发时间，记录页按今日、明日展示计划，保留至预计出发时间后一小时，点击启动图标即可绑定路线与方向记录。
- **管理路线**：同一条路线汇集上班、下班两套轨迹，保存后自动匹配，也可手动修正。
- **查看统计**：按月份和路线查看双向总里程、通勤天数和行程次数，再分方向查看耗时和图表。
- **合并分段记录**：选择同一次出行的多条记录，核对时间和位置衔接后合并；保留原片段，支持撤销合并。
- **回顾行程**：查看时间分配、停车情况、轨迹和历史比较，支持修正归类、调整起止范围、排除或删除记录。
- **行程月历**：左右滑动切换月份，下方列出当月全部行程；有行程的日期显示每日总公里数圆点，本月内里程越长颜色越深。
- **放大轨迹**：点开行程或路线轨迹，双指缩放、拖动或一键查看全程；行程由红到绿表示由慢到快，灰色表示速度未知，标注 30 秒以上的停车等待。
- **可选百度底图**：在 APK 设置中填写自己的 Android SDK AK；记录中可显示当前位置和轨迹。未配置、关闭或离线时仍可使用本地轨迹、记录与统计。
- **地图显示选项**：大图可选择简约、标准、卫星或自定义风格，开关速度着色、停留、起终点、地点名称和实时路况；停留气泡自动避开轨迹，小图保持简洁。

## 开始使用

1. 打开 APK，按手机提示完成安装；升级时直接覆盖安装，避免卸载导致记录丢失。
2. 停车后点击“开始记录”，允许精确位置并打开系统定位。
3. 结束时选择 **取消**继续记录、**删除**丢弃本次行程，或 **保存**保留记录；通知结束入口和自动到达提示也使用这三个选项，等待选择时仍在记录。
4. 保存后检查路线匹配结果，从列表选择已有路线，或点击首项“创建新路线”；已有路线缺少上班或下班方向时，可用本次轨迹补充。
5. 在“统计”选择月份和路线，再切换上班／下班；在“行程”打开行程查看详情。

默认中文，可在右上角“设置”中更改语言和天气服务。默认使用 Open-Meteo；切换和风天气时需填写[和风控制台](https://id.qweather.com/)中的 API Host 和 API Key，再保存。天气可关闭。请停车后操作。

百度地图默认关闭，不需要 AK 即可使用核心功能。开启方式：设置 → 百度地图与路况 → “复制包名与 SHA1”，在[百度控制台](https://lbsyun.baidu.com/apiconsole/key)为自己的账号创建并绑定 **Android SDK** 类型 AK，填回 APK、开启并保存。也可以从轨迹大图右上角进入地图设置。默认采用简约底图；需要“茶田”等风格时，在自己账号的[样式编辑器](https://lbsyun.baidu.com/index.php?title=open/custom)发布样式，将 ID 填入地图设置并保存，再在大图的“显示”中选择“自定义”。自定义样式加载失败不影响轨迹。不同签名的 APK 需要对应的 SHA1。

申请步骤及可直接复制的签名信息见[百度地图设置指南](docs/baidu-map-setup.zh-CN.md)。

早期版本中按星期设置的出行计划会保留为“自定义星期”；如需按节假日和调休推荐，可在路线的出行计划中切换为“工作日”。

## 权限与运行条件

| 权限或条件 | 用途与影响 |
|---|---|
| 精确位置 | 记录轨迹、识别路线；拒绝或仅允许近似位置时无法开始记录，仍可查看历史 |
| 近似位置（仅天气） | 查看当前位置天气；天气定位授权不会开始记录，未授权时可查看已有路线起点天气 |
| 网络与网络状态 | 获取天气及可选百度底图；离线时使用本地轨迹，仍可记录和查看历史 |
| 通知（Android 13+） | 显示记录状态和结束入口；拒绝后需回到应用结束记录 |
| 系统定位开启 | 获取定位点；关闭或信号不足时继续计时，无法判断的时间记为未知 |

不需要“始终允许”的位置权限；不会开机自启或自动开始骑行。

## 使用说明

- **出行计划**：在“路线”中打开路线，选择上班或下班，再设置出行计划；默认“工作日”，按内置中国节假日安排排除假期、包含调休补班；也可选择“自定义星期”，全部取消则不推荐该方向。已内置 2026 年安排，其他年份随应用更新，未提供安排的年份无法按工作日推荐，可改用“自定义星期”；日历可离线使用。出发时间可手动设置，或使用历史常用时间；无历史时，上班参考 08:00、下班参考 18:00。
- **今日与明日路线**：展示有计划且尚未超过预计出发时间一小时的路线，按出发时间排序；恰好晚一小时仍保留，超过后移除。深夜计划跨零点后可在今日列表继续查看，仍显示原计划时间。不会自动开始记录。计划按手机当前时区解释。
- **天气与出发时段**：推荐路线汇总起终点在计划出发至历史中位耗时结束时段的体感温度和降水概率；没有历史耗时时查看后一小时。路线卡片不再显示风况。
- **路线交通**：在“设置 → 百度地图与路况”开启“推荐路线实时路况”；[配置说明](docs/traffic-setup.zh-CN.md)。总设置、轨迹地图和推荐卡片进入同一个配置，已填 Android SDK AK 自动保留，无需新增服务端密钥；底图与推荐路况可分别开关。出发前两小时至后一小时，在未开始记录且记录页可见时，与天气同步刷新。按规划路线参考展示，允许绕行及一定偏差，显示路线相似度、里程差及起终点偏差。反向、相距过远或缺少路线时不展示参考；数据不足或超过 20 分钟不显示为畅通。耗时为驾车参考，不代表实际摩托车耗时，也不改变记录中的历史预计到达。暂不提供未来预测或最佳出发时段。
- **天气刷新**：记录页可见时定期查询，下拉页面可同时刷新当前天气及今日、明日路线预报；正常情况下天气数据保留 20 分钟，刷新失败时保留可用的近期数据并显示简短提示，仅当前天气显示更新时间；网络请求可能需要数秒。天气来源统一显示在记录页底部。天气不影响离线记录，暂无后台天气提醒。
- **路线与历史**：新建路线至少需要四个有效定位点和 150 米轨迹，起终点半径可设为 20–500 米；至少三次同方向可用历史后才显示历史对比和预计到达。
- **到达提示**：接近终点并持续低速停留至少 30 秒后才可能提示到达，仍需选择保存或删除；路线相近、偏离或定位不足时，识别和预计到达可能不可用。
- **时间口径**：总耗时等于移动、静止与未知之和；预计到达不包含实时路况。
- **地图与停留**：大图右上角“显示”可切换底图风格和内容，选项保存在本机；停留开关只影响大图，小图不显示停留点或气泡。无空位时气泡会隐藏，放大可查看。实时路况表示当前道路状况，不是历史行程速度。
- **亮屏与耗电**：记录时应用在前台保持亮屏，离开应用或结束记录后恢复正常休眠；可按电源键锁屏，后台继续记录，持续定位和亮屏会增加耗电。
- **合并行程**：点击“行程”顶部的合并图标，或长按行程／在详情更多操作中选择“合并行程”，可跨月份选择 2–10 段，自动按时间排序并显示间隔和首尾距离。相邻片段不得重叠，间隔不超过 30 分钟，首尾相距不超过 300 米；定位不足、路线方向冲突或漏选中间行程会提示原因。先结束正在录制的行程；合并总时长最多 12 小时。沿用调整后的起止范围，中断记录以最后保存的定位点为终点。未录制的间隔计为未知，不补画轨迹或推算里程，主动排除状态保留；未知时间过多时仍不计入有效通勤。合并后列表只显示一条记录，详情更多操作可撤销；再次合并最多包含 10 段原始记录，撤销恢复到本次合并前。删除合并结果会同时删除保留的原片段，已保存路线仍保留。
- **修改与删除**：长按行程或路线卡片打开管理菜单，进入路线后，关联行程随上班／下班切换，可打开详情或长按解除关联；删除路线保留行程，删除行程会移除原始轨迹。
- **数据保存位置**：设置中显示行程数据库的实际路径，可长按复制，或点击“用文件管理器打开”只读浏览数据库及其辅助文件；文件管理器需支持系统文档访问，不支持时会尝试系统文件选择器。此入口不提供编辑、删除或恢复数据功能。
- **中断与恢复**：首次定位耗时取决于环境；若记录中断，先检查定位和应用后台限制，重新打开后可查看已保存部分，但不会自动续录。

## 数据与限制

开启推荐路线实时路况后，会通过百度地图查询路线起终点及关键途经点，轨迹核对在本机完成，不发送整段原始行程；该查询比天气使用更具体的位置。路况功能默认关闭，复用已加密保存的地图 AK，其可用性及额度以百度账号权限为准。

行程和完整轨迹保存在本机，不上传到轨迹云；速度与停车分析也在本机完成。天气开启时，会向所选服务发送保留两位小数的当前位置或路线起终点经纬度。和风与百度密钥加密保存在本机，不随备份保存。开启百度地图、填写 AK 并查看地图时，百度地图服务会按其[隐私政策](https://lbsyun.baidu.com/index.php?title=openprivacy)处理位置、查看的地图区域、IP 和设备相关信息，因此联网地图无法完全离线使用。查看地图不会更改历史轨迹。**卸载或清除应用数据会丢失记录，目前不提供应用内导出、导入或云端恢复。**

[Open-Meteo 免费接口](https://open-meteo.com/en/pricing)适用于非商业使用，和风的可用接口与额度以个人账号为准。天气是网格预报，路线预览取起终点数据，不能覆盖沿途每个地点，也不代表路面状况。

轨迹大图、速度着色与停车标注可离线使用；百度底图及实时路况需要自己的有效 AK、网络和账号权益。定位不足时隐藏当前位置标记，定位缺口和跳点不补线，未知速度不记作零速。路线参考图不借用来源行程的速度或停车数据。暂不支持导航或红灯识别；定位精度和后台连续性受环境及手机系统影响。

默认安装包适用于 **64 位 ARM（arm64-v8a）** 手机。
