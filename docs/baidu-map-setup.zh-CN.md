# 百度地图 AK 设置

途记不要求用户共用开发者的 Key；每个人可以在 APK 中填写自己账号下的 Android SDK AK。没有 Key 或不开启地图时，本地轨迹大图、缩放、速度颜色、停车分析、记录和统计均可使用。

1. 登录[百度地图开放平台控制台](https://lbsyun.baidu.com/apiconsole/key)，按页面提示完成开发者注册／认证。
2. 进入“应用管理 → 我的应用 → 创建应用”，应用名称可以填“途记”，应用类型选择 **Android SDK**。
3. 在 APK 的“设置 → 百度地图”点击“复制包名与 SHA1”，填入控制台对应字段。也可直接使用当前项目共享签名的信息：

   - 包名：`com.ridediary`
   - SHA1：`FD:FB:9B:E9:10:90:FD:1D:16:19:2B:24:64:B6:99:3B:5A:7F:E3:9F`

   当前本地 Debug 和 Release 性能包使用同一共享签名，开发版与发布版 SHA1 字段可填同一个值。以后若换用其他证书签名，应以新 APK 设置里复制的 SHA1 为准。
4. 确认启用地图 SDK 所需服务，提交后复制生成的 AK。不要创建成浏览器端或服务端类型。
5. 回到 APK 的“设置 → 百度地图”，粘贴 AK，开启开关并保存；重新打开轨迹大图。初次配置先把样式 ID 留空，以便确认基础地图正常。
6. 如需“茶田”样式，在自己账号的[地图样式编辑器](https://lbsyun.baidu.com/index.php?title=open/custom)选择该模板并发布，复制样式 ID，再填入 APK 的可选样式 ID 字段并保存。在轨迹大图右上角“显示 → 底图风格”中选择“自定义（茶田等）”并应用。升级前已填写的样式 ID 会默认继续选用。

大图的“显示”也可切换简约／标准／卫星底图，并分别控制速度着色、停留点与时长气泡、起终点、地点名称和实时路况。选项保存在本机；轨迹内容开关同时影响本地离线轨迹。实时路况表示当前道路状况，不用于解释历史行程速度。

若底图未显示，检查 AK 类型、包名、冒号分隔的完整 SHA1、地图服务权限及网络；错误不影响本地轨迹。AK 不需要发给其他人，直接保存在 APK 即可。

官方说明：[注册和获取密钥](https://lbs.baidu.com/docs/guide?title=android-guide/create-project/ak)。当前证书 SHA1 已通过本地 APK 的 `apksigner verify --print-certs` 核实。
