# 推荐路线的路况设置

[English](traffic-setup.en.md)

1. 打开“设置 → 百度地图与路况”。轨迹地图中的设置及推荐卡片的配置入口也会打开同一个面板。
2. 之前填写的 Android SDK AK 会自动保留，不用再次输入，也不用新增服务端 AK。第一次配置地图时，按[百度地图设置指南](baidu-map-setup.zh-CN.md)填写自己的 Android SDK AK。
3. 打开“推荐路线实时路况”，点击“保存百度设置”。底图与推荐路况可以分别开关，共用同一个 AK；推荐路况默认关闭。
4. 在计划出发前两小时至后一小时，打开记录页或下拉刷新。路况与天气同步，上班、下班分别查询；其他页面、后台及记录过程中不查询推荐路况。

本版只查询**当前路况及驾车参考耗时**，暂不提供未来路况预测或最佳出发时段。查询使用百度 Android SDK 的含路况路线能力：[官方接口说明](https://lbsyun.baidu.com/cms/androidsdk/doc/v4_0_0/com/baidu/mapapi/search/route/DrivingRoutePlanOption.DrivingTrafficPolicy.html)。可用权限与额度仍以自己的百度账号为准。

耗时为**驾车参考**，不是实际摩托车耗时，也不是导航指引。数据不足或过期不会显示成畅通，不用历史行程代替实时路况。卡片显示更新时间，有可比较的前次数据时显示拥堵加重、缓解或变化不大。

路况默认折叠，只显示当前状况和驾车参考耗时。点击右侧箭头展开更新时间、拥堵变化及路线相似度与偏差，再次点击收起；各推荐路线分别控制。

查询向百度发送路线起终点及关键途经点；保存轨迹与查询结果的比较在本机完成。路况按规划路线参考展示，允许途中绕行及一定的起终点偏差，不再因轻微差异隐藏结果。卡片展示与保存路线的相似度、里程差和起终点偏差；相似度是附近约 100 米且方向相近的路程估计，不代表精确道路重合。明显反向、相距过远或缺少可用轨迹时仍不展示参考，不会更改保存路线或原始行程。

实时路况数据最多展示 20 分钟。若提示权限或密钥不可用，请检查已有 Android SDK AK 绑定的包名、签名及服务权限，不需要复制成另一个密钥。未启用或查询失败时，仍可正常离线记录和查看统计。
